CCANH site test plan

Crane Camera Automated Navigation Hub 0.4.0: offline deployment and acceptance test on a restricted-network Windows 11 machine. Sections 5b, 5c and 5d cover what changed in 0.2.0, 0.3.0 and 0.4.0 (site feedback). Since 0.3.0 the admin pages are behind the ⚙ Settings cog (top right); "⚙ Settings → Users" means: click the cog, then Users in the sidebar. Sign out and Account are in the menu on your name. Results are saved in this browser as you go; use Export results (CSV) to keep them, and Print for paper.

1. Scope and how to use this plan

  • Goal: confirm that CCANH installs and runs on a standard Windows 11 machine with nothing else installed and no internet access, and that every feature works with the site's AXIS cameras.
  • Package contents: crane-setup-<version>.exe (installer), portable\crane.exe (same program, no install), tools\Test-Ccanh.ps1 (automated checks), tools\Collect-Diagnostics.ps1 (problem report), SHA256SUMS.txt, this plan and README.txt.
  • Nothing else is needed: no Visual C++ runtime, .NET, Node, database server or internet. The web interface is built into crane.exe and is used with Microsoft Edge (part of Windows 11).
  • Order: sections 2–4 first (install, first run). Section 5 (demo mode) can be done any time and needs no cameras. Sections 6–12 need cameras. Cases marked critical are the acceptance criteria; the rest are recommended.
  • Run PowerShell as administrator for all commands here (the data folder is readable by administrators only). If scripts are blocked: powershell -ExecutionPolicy Bypass -File .\tools\Test-Ccanh.ps1.
  • Never record real passwords in the notes. Camera IP addresses are fine to note on site, but remove them before sharing results outside the network.
  • If something fails: set the case to Fail, describe what you saw, run tools\Collect-Diagnostics.ps1 (creates a zip on the Desktop without the database or keys) and keep it with the exported CSV.
